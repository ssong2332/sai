## 금지 (다른 모든 것보다 우선)

- 🔴 **한 컷에서 막히면 그 컷을 건너뛰고 다음으로 간다.** 현장에서 원인을 찾지 않는다.
- 🔴 **API를 쓰는 컷은 재촬영이 비싸다.** B 구간은 대사를 먼저 연습하고 **한 번에** 간다.
- 🔴 여기 적힌 문장을 **그대로** 쓴다. 즉석에서 바꾸면 기대 결과와 어긋나 「고장인가?」로 시간을 버린다.

## 0-A. 🔴 전날/직전에 «미리» 해 둘 것

촬영 중에 세팅하면 화면이 지저분해지고, 안 해 두면 **A2·A6 컷이 아예 안 나온다.**

| # | 준비 | 왜 |
|---|---|---|
| 1 | **프로필에 이름·역할·말투를 채워 둔다** | A2의 접힘 요약(`홍길동 · 백엔드 · 직접적으로`)은 **셋이 다 있어야** 나온다. 비어 있으면 카드가 펼쳐진 채라 「접힌다」를 못 보여준다 |
| 2 | **저장 문구 2~3개 등록** | A6에서 `Alt+X`를 눌렀을 때 빈 목록이면 컷이 죽는다 |
| 3 | 🔴 **수신자를 「뉴욕」으로 등록** | 아래 시간표 참고 — 예약 컷이 시간에 걸려 실패하는 것을 막는다 |
| 4 | **시연용 페이지를 정해 둔다** | 아래 참고 |
| 5 | 브라우저 정리 | 북마크바 숨기기 · 다른 확장 끄기 · 알림 끄기 · 시크릿 창 금지(확장이 안 뜬다) |

### 🔴 시연용 페이지 — 개인정보가 안 나오는 곳으로

`chrome://` 페이지에서는 팝업이 뜨지 않는다(크롬 정책). 그렇다고 **평소 쓰는 Gmail·Slack을 열면
받은편지함·대화 목록이 그대로 영상에 나간다.**

| | 안 | 비고 |
|---|---|---|
| 🟢 **권장** | Gmail **새 창 작성 화면**(`mail.google.com` → 편지쓰기, 받는사람 비움) | 실제 업무처럼 보이면서 목록이 안 나온다 |
| 🟢 | 새 Google 문서 / 아무 사이트의 댓글 입력창 | 가장 안전 |
| 🔴 금지 | 받은편지함 · 사내 Slack · 실제 프로젝트 도구 | 개인·회사 정보 노출 |

### 🔴 사이드패널에 «내 이메일»이 뜬다

설정의 「연결된 서비스」 카드에 로그인 계정이 그대로 보인다. 셋 중 하나로 처리한다:
**① 데모용 구글 계정으로 로그인** ② 그 카드가 보이지 않게 스크롤 ③ 편집에서 흐리기.

### 🔴 예약 컷(B5) — 도시에 따라 «버튼이 안 뜬다»

퇴근 시간대 판정은 **상대 현지 18:00~09:00**이다(`src/core/schedule/fairy.js`).

| 수신자 도시 | 퇴근 시간대가 되는 **한국 시각** | 오전~오후 촬영 |
|---|---|---|
| 베를린 | 01:00 ~ **16:00** | 🔴 16시 넘으면 버튼이 안 뜬다 |
| **뉴욕** | **07:00 ~ 22:00** | 🟢 한국 낮 내내 안전 |

→ **수신자는 뉴욕으로 등록한다.** 베를린으로 찍으려면 **오후 4시 전**에 끝내야 한다.

### 「오늘의 사이」 카운트

0이면 화면이 비어 보인다. **A 구간 리허설을 한 번 돌면** 저장 문구·예약 카운트가 쌓인다
(카운트는 이 기기에 남는다). 교정 카운트를 올리려면 호출을 쓰므로, **B 구간 리허설 1회로 충분**하다.

| # | 확인 | 기대 |
|---|---|---|
| 0-1 | `chrome://extensions`의 S·AI 버전 | **0.1.5** |
| 0-2 | 사이드 패널 로그인 상태 | 구글 계정 로그인됨 |
| 0-3 | OpenAI 잔여 요청 | 아래 명령으로 확인 |
| 0-4 | 화면 배율 · 알림 끄기 | 카톡·메일 알림 끄기 |

```bash
curl -s -D - -o /dev/null -X POST https://api.openai.com/v1/chat/completions -H "Authorization: Bearer $OPENAI_API_KEY" -H "Content-Type: application/json" -d '{"model":"gpt-4o","messages":[{"role":"user","content":"hi"}],"max_tokens":1}' | grep -i remaining-requests
```

🔴 **`gpt-4o`는 한국 시간 05:30경 50건으로 초기화된다.** 그 이후에 시작한다.
🔴 한도에 걸려도 **자동으로 Gemini → gpt-4.1로 넘어간다**. 문장이 조금 달라질 수 있으나 고장이 아니다.

# A 구간 — API 호출 **0건**

## A1. 설치와 첫 실행

1. zip 압축 해제 → `chrome://extensions` → 개발자 모드 ON → 압축해제된 확장 로드
2. **주소창 옆 퍼즐 아이콘** → S·AI → 압정으로 고정
3. 사이드 패널에서 **구글 로그인**

> 대사: 「설치는 압축 풀고 폴더 하나 고르면 끝입니다. 로그인해야 교정이 됩니다.」

## A2. 「내 정보」 — 접힘과 펼침

1. **프로필** 탭 → 접힌 요약 `홍길동 · 백엔드 · 직접적으로`
2. **바꾸기** → 이름·역할 · 내 언어 · 1순위(상황·말투) · 2순위가 펼쳐짐
3. **선호하는 말투 5종**을 보여준다 — 직접적으로 / 부드럽게 / 짧게 / 결론 먼저 / 근거를 함께

> 대사: 「설정을 마치면 한 줄로 접힙니다. 매일 볼 값이 아니니까요.」

## A3. 내가 대화하는 사람들

1. **＋ 새 사람 추가** → 이름 `Miguel` · 지역 **`뉴욕`** · 언어 `영어`
   🔴 0-A의 시간표 참고 — 베를린은 한국 16시 이후 예약 컷이 실패한다
2. 태그 2개 정도만 켠다 (예: 「결론 먼저 선호」)

> 🔴 **숫자 점수가 없다는 점을 말한다** — 사람을 평가하지 않고 «어떻게 쓸지»만 적는다.

## A4. 시차 — 듀얼 클락 · 회의 시간 추천

1. 홈 탭의 **듀얼 클락**(내 시각 / 상대 시각)
2. **회의 시간 추천** 카드를 눌러 펼친다 — 양쪽 업무시간이 겹치는 구간

> 🔴 캘린더 연결은 **찍지 않는다** — 「Google에서 확인하지 않은 앱입니다」 경고가 뜬다.

## A5. 🔴 민감정보 차단 — **하이라이트**

입력창에 아래를 **그대로** 붙여넣고 드래그 → 다듬기:

```
DB 접속 정보 보내드립니다. 계정은 admin이고 비밀번호: Sunrise2026! 입니다.
```

**기대**: 「민감한 정보가 있어 AI에 보내지 않았어요」 — **AI를 부르지 않는다(호출 0건)**

다른 예시(둘 다 발동 확인됨):
```
결제 테스트용 카드번호 4242 4242 4242 4242 로 한 번만 돌려봐 주세요.
```
```
API 키 sk-proj-abc123def456ghi789jkl012mno345pqr678 를 그대로 쓰시면 됩니다.
```

> 대사: 「보내기 전에 잡습니다. 이건 AI로 아예 나가지 않습니다.」

## A6. 저장 문구 — `Alt+X`

1. 미리 문구 2~3개를 등록해 둔다
2. `Alt+X` → 즉시 목록

> 🔴 **AI를 부르지 않아 한도를 쓰지 않는다**는 점을 말한다. 자주 쓰는 문장의 재사용 경로다.
> 단축키가 안 잡히면 **로고에 커서를 올려** 나오는 버튼으로 대체한다.

## A7. 용어집

1. 개인 용어집에 `배포 → rollout` 등록
2. 팀 용어집 탭도 잠깐 보여준다

## A8. 오늘의 사이 · 보관함

홈의 카운트와 보관함(저장 문구 · 예약)을 짧게 훑는다.

# B 구간 — API 사용 (약 **6회 교정 = 12요청**)

## B1. 다듬기 기본 — 1회

```
오늘 회의에서 나온 피드백 정리해서 내일 오전까지 보내드릴게요.
```

**볼 것**: 교정문 · **역번역**(한국어 뜻) · 긴급도 배지 · 「적용하기」로 입력창 치환

## B2. 🔴 **말투 3종 비교 — 이 시연의 핵심** (3회)

같은 문장을 **말투만 바꿔** 세 번 돌린다.

```
바쁘신 와중에 죄송한데요, 지난번에 말씀드린 API 문서 초안을 이번 주 금요일까지 공유해 주실 수 있을까요? 팀 리뷰가 다음 주 월요일이라서요.
```

| 순서 | 말투 | 기대 (2026-08-20 실측) | 쓰임 |
|---|---|---|---|
| 1 | **부드럽게** | `I apologize for interrupting your busy schedule, but could you please share …?` | 외부 협력사·이메일 |
| 2 | **직접적으로** | `Please share the draft API documentation … as the team review is scheduled for next Monday.` | 사내 메일 |
| 3 | **짧게** | `Could you share the API doc draft …? Team review is next Monday.` | Slack·Teams |

> 🔴 **대사는 「말투 3종」이 아니라 「상황 3종」으로 한다.**
> 「같은 문장을 외부 협력사에게, 사내에, 슬랙에 보낼 때 — 세 가지가 다릅니다.」
> 그게 심사위원에게 훨씬 빨리 이해된다.

**보여줄 두 축** (둘이 서로 반대라는 것이 요점):

| | |
|---|---|
| 정중함 | 부드럽게 > 직접적으로 > 짧게 |
| 길이 | 짧게 < 직접적으로 < 부드럽게 |

🔴 **세 결과 모두에 「금요일」과 「월요일」이 남아 있다는 것을 짚는다** — 톤을 바꿔도 사실은 안 바뀐다.

## B3. 뜻 풀기 — 1회

상대가 보낸 영어 메시지를 드래그:

```
Just circling back on this — no rush, but it would be great to have your input before the sync tomorrow morning.
```

**볼 것**: 직역 / **실제 의도** / **체감 긴급도** / 요구 행동

> 대사: 「`no rush`라고 쓰여 있지만 **내일 아침 전까지** 필요합니다. 그 간극을 풀어 줍니다.」
> 🔴 이 제품 이름(「사이」)이 가리키는 바로 그 지점 — 의도와 읽힘 사이.

## B4. 하소연 → 티켓 — 1회

```
이번 스프린트도 또 이렇게 됐네요. 매번 기획이 중간에 바뀌니까 개발이 계속 갈아엎어지고, 팀 다 지쳐 있습니다.
```

**기대**: 「티켓 형태로 변환할까요?」 제안 → **문제점 / 영향 / 요청사항** 3단 구조

> 🔴 **요청이 섞이면 하소연으로 판정되지 않는다**(설계상 그렇다). 위 문장은 요청이 없어 판정된다.
> 안 뜨면 그냥 넘어간다 — 현장에서 문장을 고치지 않는다.

## B5. 예약 발송 — 0회 (B2 결과 재사용)

수신자를 **뉴욕(A3에서 등록)**으로 두면 한국 낮 전체가 상대 퇴근 시간대다(07:00~22:00 KST).
B2의 결과 화면에서 **🌙 예약** 버튼을 눌러 보관함에 쌓이는 것을 보여준다.

> 대사: 「지금 보내면 상대는 새벽에 알림을 받습니다. 업무시간에 도착하게 예약합니다.」

## 촬영 중 문제 대응표

| 증상 | 원인 후보 (순서대로) | 대응 |
|---|---|---|
| 「로그인이 필요해요」 | 로그인 안 됨 / 토큰 만료 | 사이드 패널에서 재로그인 |
| 「교정하지 못했어요」 | ① 한도 소진 ② 연속 호출 ③ 네트워크 | **15초 기다렸다 한 번만** 재시도. 두 번 실패하면 그 컷 건너뛴다 |
| 문체가 아까와 다름 | 폴오버로 다른 모델이 답함 | **고장 아님.** 그대로 간다 |
| 팝업이 안 뜸 | `chrome://` 페이지 | 일반 웹페이지에서 한다 |
| 단축키 무반응 | 다른 프로그램과 충돌 | 로고 hover 버튼으로 대체 |
| 결과가 옛날 것 같음 | 확장이 옛 버전 | `chrome://extensions`에서 **0.1.5** 확인 |
