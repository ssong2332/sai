## 1-6. 13-3 저장소 전수 검사 결과 (2026-08-14) — **S27 체크리스트 완료**

`await chrome.storage.local.get(null)` (서비스 워커 콘솔). 저장된 20개 키 전부:

| 분류 | 키 | 판정 |
|---|---|---|
| 설정·토글 | `backTranslation` `casualTone` `highlightHints` `theme` `threadContext` `threadContextPreview` `snippetInsertMode` `decisionsConsent` | ✅ 불리언·enum |
| 수치·집계 | `feedback {down:3, up:3}` · `points {balance:380, history:13건}` | ✅ **숫자와 고정 사유 코드뿐** — `points.history` 항목은 `{reason(enum), amount(number), at(ISO)}` 형태로 본문이 들어갈 자리가 없다 |
| 학습 결과 | `profile.learned {fewer-apologies: 1}` | ✅ **핵심 확인** — S13 Diff 학습이 문장이 아니라 **카테고리별 횟수**로만 남는다 |
| 메타데이터 | `onboarding` · `profile` · `recipients`(3) · `recipients.selected` · `glossary.personal`(5) | ✅ 설정·이름·타임존·용어쌍 — 메시지 본문 아님 |
| **문서화된 예외** | `snippets`(5) · `reservations`([]) · `decisionLogs`(1) | 🟢 **정상** — 사용자가 버튼을 눌러 직접 저장한 것. 서버로는 나가지 않는다 |

→ **본문이 새어 나간 키 0건.** Spec 필수 5 충족.

🔴 **부수 발견 — 죽은 키 1개**: `sai.urgentTag`가 남아 있었다. URGENT 태그를 상시 적용으로 바꾸며 읽기를 없앴고, 스위치를 되살릴 때는 **저장 없이 매 결과마다 초기화되는** 상태로 만들어서(의도된 설계) 쓰는 곳이 하나도 없는 잔재가 됐다. `storage.js`의 상수를 삭제했다. 이미 값이 저장된 브라우저에는 남아 있으나 아무도 읽지 않는다(지우려면 `chrome.storage.local.remove('sai.urgentTag')`).

🔴 **13-3은 세 번 만에 통과했고 두 번의 실패는 모두 내 절차 오류였다**: ① 일반 웹페이지 콘솔에는 `chrome.storage`가 없다 ② `console.log` 출력이 **콘솔 필터**(`사이`)에 걸려 숨겨졌다. → 저장소 검사는 `console.log` 대신 **`await chrome.storage.local.get(null)`로 반환값을 보게** 안내한다. 필터·빈 문자열에 걸리지 않는다.
