## 1. 디스콰이엇 (메이커 로그 · 프로덕트 등록)

**제목**: 해외 동료에게 보내는 메시지, 보내기 전에 한 번 다듬어 주는 크롬 확장 「사이」를 공개했어요

```
해외 팀과 일하면서 제일 오래 붙잡고 있던 게 코드가 아니라 슬랙 메시지였어요.
"이거 너무 세게 읽히나?", "급하다는 게 전달되나?", "이 사람 말이 진짜 괜찮다는 건가?"

그래서 만든 게 사이(SAI)예요.

• 입력창에서 문장을 선택하고 아이콘을 누르면, 상대 언어로 다듬은 문장과
  무엇을 왜 바꿨는지, 상대에게 어떻게 읽히는지(역번역)를 같이 보여 줘요.
• 받은 메시지를 선택하면 직역 말고 실제 의도·긴급도·해야 할 일을 풀어 줘요.
• 회사 용어집을 넣어 두면 그 용어를 지키고, 빠지면 다시 다듬어요.
• 상대가 퇴근 시간이면 현지 근무 시간에 보내라고 알려 줘요.

개인정보가 제일 신경 쓰였던 부분이라, 메시지 본문은 서버·DB에 저장하지 않게 만들었어요.
키·카드번호 같은 민감정보는 보내기 전에 기기에서 막아요.

지금은 팀 기능까지 전부 무료예요(하루 20회). 1인 개발이라 써 보시고 이상한 결과나
불편한 점을 댓글로 알려 주시면 정말 큰 도움이 됩니다.

설치: (스토어 링크)
소개: (소개 사이트)
```

태그 후보: 생산성 · 크롬 확장 · AI · 글로벌 협업

## 2. GeekNews (Show GN)

**제목**: Show GN: 사이 – 해외 협업 메시지를 보내기 전에 다듬고, 받은 메시지 속뜻을 풀어 주는 크롬 확장

```
해외 동료와 일할 때 쓰는 업무 메시지용 크롬 확장입니다. 1인 개발이고 오늘 스토어에 공개했습니다.

- 아무 사이트 입력창에서 문장을 선택 → 상대 언어·긴급도에 맞게 다듬고, 바꾼 이유와 역번역을 함께 보여 줌
- 받은 메시지 → 직역 / 실제 의도 / 겉보기와 실제 긴급도 / 해야 할 일
- 개인·팀 용어집: 결과에 용어가 빠지면 서버가 대조해서 다시 부르고, 일부만 들어가면 경고
- 품질 모드 3단(빠른·기본·심층) — 모델은 서버가 고르고 확장은 모드 이름만 보냄

구조
- 크롬 MV3 + React, 교정 서버는 Cloudflare Workers, 모델은 Anthropic Claude(장애 시에만 Groq)
- 메시지 본문은 서버·DB·로그에 저장하지 않음(횟수 같은 숫자만). 민감정보는 전송 전 기기에서 차단
- 비용 때문에 하루 20회, 월 추정 비용이 일정 선을 넘으면 상위 모드 → 빠른 모드, 더 넘으면 그달은 멈춤

지금은 무료입니다. 피드백 환영합니다.
(스토어 링크)
```
