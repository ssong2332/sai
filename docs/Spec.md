## 1. 📌 프로젝트 개요 및 비즈니스 아키텍처

* **제품명**: 사이 (Sai) - 사람과 사람, 언어와 언어 사이를 매끄럽게 잇는 소통 도우미
* **타겟 언어**: 한국어 ↔ 영어, 중국어 (1차 핵심 타겟)
* **디자인 컨셉**: 무채색(White/Gray) Base + 주황(Orange)/초록(Green) Accent
  * 🔴 **다크 모드를 v1에 포함한다** (2026-08-12 사용자 결정 — [DS] 프로토타입에 다크 토큰이 이미 확정돼 있어 추가 비용이 거의 없다). 토큰 단일 출처는 `src/styles/tokens.css`.
* **UI 아키텍처 (삼원화)**
  * **In-page 팝업**: 텍스트 드래그 시 가볍게 뜨는 교정(작성 모드) 및 해독(수신 모드) 전용 UI.
  * **Side Panel (사이드 패널)**: 크롬 toolbar 아이콘 클릭 시 우측에 열리는 종합 설정 패널 (`chrome.sidePanel` API 기반 — 온보딩, 용어집, 개인 프로필, 스니펫, 학습내역, B2B 팀 데모).
  * **Web Dashboard**: B2B 리더용 대시보드 및 프로젝트 시각화 공유 웹페이지.
* **수익화 및 재화 시스템 (Token Economy)**
  * **개인(Free)**: 기본 교정 및 서술형 수신자 소통 가이드(기본 3개) 무료.
  * **기업/팀(B2B 유료 구독 - v2)**: 팀 용어집 동기화, 조직 간 협업 건강도 지수 & 마찰 리포트 연동(`Health Score = 100 - Friction Index`), 엔터프라이즈 보안 옵션.
  * **인앱 재화(Token/Point)**: 회의 시간 양보, 퇴근 요정 수락, 1초 피드백 참여 시 포인트 획득 ➔ 소통 가이드 상세 확장 및 유료 열람에 사용 가능.

## 2. 🔴 필수 기능 (Must-have: MVP 핵심 기능 - v1)

### 📌 [필수 1] 긴급도 분류 기반 톤 변환
* 사용자가 긴급도(Critical/Normal/Low)를 직접 선택/지정할 수 있으며, 미선택 시 **AI가 문장을 분석해 1차 판정**해 기본값으로 제시하고 사용자가 언제든 변경 가능. AI 판정 자체가 실패한 경우에만 기본값 'Normal'을 적용하고, 실패 사실을 사용자에게 명시적으로 알림.

### 📌 [필수 2] 수신자 프로필 참고 우선순위 최적화 (국가 고정관념 방지)
* **1순위 (최우선):** 사용자가 작성한 '상황(Situation) 템플릿(코드리뷰, 장애 등)' 및 '개인 협업 성향'
* **2순위:** 3회 이상 축적된 개인 수정 패턴 (Diff 학습)
* **3순위 (가장 낮음):** 국가/문화권 일반 특성 (국가 단위 뭉뚱그리기 방지)
* *과도기 규칙: 개인 수정 패턴이 3회 미만일 때는 1순위만 100% 반영.*

### 📌 [필수 3] 백트랜슬레이션(역번역) 상시 노출 & 토글
* 번역된 외국어 문장 바로 아래에 역번역(한국어 뜻)을 **기본적으로 항상 노출**하며, 토글 버튼으로 ON/OFF 가능 (`chrome.storage.local` 저장).

### 📌 [필수 4] 하소연 → 태스크 티켓 변환
* 감정적인 불만(하소연) 텍스트 감지 시 "티켓 형태로 변환할까요?" 제안. 수락 시 **[문제점 / 영향 / 요청사항]** 3단 구조로 자동 변환 (감정은 '우려 수준' 메타데이터로 보존).

### 📌 [필수 5] 심리스 교체 & Zero Retention(당사 서버 기준) & 클립보드 복사 폴백
* 텍스트 승인 즉시 원래 입력창의 글자 직접 치환 + **당사 서버·DB에는 메시지 본문을 저장하지 않음** (Zero Retention). AI 처리를 위해 OpenAI API로 전송되며, 학습에는 사용되지 않으나 벤더 정책에 따라 일시 보관될 수 있음. DOM 교체 실패 시 **"클립보드에 자동 복사되었습니다 (Ctrl+V)"** 예외 처리.

### 📌 [필수 6] 퇴근 요정 (비동기 예약 발송 & 휴일 연장 & 업무시간 학습)
* 상대방 퇴근시간(18:00~09:00) 및 새벽일 경우 **현지 아침 9시 예약발송을 자동 세팅 제안**.
* 비긴급(Low) 모드 선택 시 퇴근 시간대에는 **즉시 전송을 완전 제한(강제 예약)**. 각국 공휴일/주말 감지 시 다음 영업일 아침 자동 연장. 상대 업무시간 자동 학습 반영.

### 📌 [필수 7] 용어 사전 (Glossary) - 크롬 사이드 패널 전용
* 크롬 사이드 패널 UI에서 접근/관리. 개인/팀/연동 용어 사전 탭 구분. 우선순위: `개인` > `팀/연동` > `기본 AI`. `[원문 유지]` 태그 지원.

### 📌 [필수 8] 트렌드 밈 수집 및 캐주얼 톤 적용 (Work-Safe Filter)
* 국가별 최신 밈 수집 및 캐주얼 톤 적용. 비속어/혐오 표현 자동 필터링(Work-Safe Filter) 필수 적용.

### 📌 [필수 9] 수신자 소통 가이드 (Recipient Communication Guide - F-07)
* **개인 단위:** 서열/낙인을 유발하는 숫자 점수 대신 **"이 사람은 [오전 응답 빠름] · [직접적 표현 선호] · [짧은 메시지 선호]"** 같은 서술형 태그 형태로 정보 제공. (개인 점수 표기는 G1/G2 조항에 의거 전면 금지되며, 대상자 본인의 열람·수정·비공개 권리 보장).

### 📌 [필수 10] 수신 메시지 해독기 (Incoming Message Decoder - F-11)
* 상대방이 보낸 외국어 메시지 선택 시 **직역, 실제 의도(문화적 완곡 표현 해독), 체감 긴급도, 요구 행동**을 다각도로 해석 노출. (예: "I have a few minor comments" ➔ **실제 의도: 전면 재작업 요구**).

### 📌 [필수 11] 로컬 민감정보 발송 가드 (Sensitive Data Guard - F-14)
* LLM 서버 전송 전, 클라이언트 로컬 정규식(Regex)으로 API 키(`sk-`, `ghp_`), 카드번호, 주민번호, 비번 등을 자동 감지해 **AI 서버 전송을 미리 차단하고 `[REDACTED]` 마스킹 처리**.

## 3. 🟡 B2B 로드맵 및 권장 기능 (v2 B2B Pipeline & Recommended)

> 💡 **F-10(조직 협업 건강도 지수)과 F-26(마찰 리포트)의 관계 정의:**
> F-10과 F-26은 동일한 데이터(하소연 감지 횟수, 퇴근시간 강행 횟수 등)를 활용하는 하나의 데이터 파이프라인입니다.
> `조직 협업 건강도(Health Index) = 100 - (정규화된 마찰 카운트)` 공식으로 산출되며, **9일 해커톤 특성상 축적된 실데이터가 없어 B2B 웹 대시보드(v2)로 합쳐져 출시**됩니다. (v1 사이드 패널에는 B2B 데모 목업(Mockup) 안내 배너로 표기).

* **[B2B v2] 조직 대 조직 협업 건강도 지수 & 마찰 리포트 (F-10 / F-26 통합)**: 조직 간 마찰 데이터를 거울상 알고리즘으로 양수/음수 시각화하여 B2B 리더 대시보드에 제공.
* **[권장 1] 긴급도 쉴드 자동 2차 재번역 알고리즘**: 톤 순화로 긴급도가 약해지면 사용자에게 보여주기 전 AI가 자동 2차 재번역하여 긴급성 복원.
* **[권장 2] 퇴근 요정 우회 경고 팝업**: 비긴급 전송 제한을 억지로 긴급도를 'Normal'로 바꿔 우회하려 할 때 경고 팝업 노출.
* **[권장 3] 역번역 AI 재번역(재생성) 버튼**: 역번역 결과 불만족 시 `↻` 재생성 버튼 제공.
* **[권장 4] 이모지 문화 오해 자동 교체 안내 & 밈 해설 팝업**: 위험한 이모지는 안전한 이모지로 즉시 자동 교체 후 안내 노출. 밈/신조어 마우스 Hover 시 한국어 해설 팝업 제공.
* **[권장 5] 용어 적용 단어 초록색 하이라이트 (🟢)**: 교정 결과창에서 용어 사전 규칙이 적용된 단어를 초록색으로 강조 표시.
* **[권장 6] 위험 표현 노란색 밑줄 하이라이트 (🟡 - F-18)**: 명령조(`You must~`), 단정적 부정, 과도한 사과(`sorry` 3회 이상)에 노란색 밑줄을 그어 2차 안전망 제공.
* **[권장 7] 공개 채널 인식 & DM 전환 안내 (F-13)**: 공개 채널에서 특정인에 대한 불만/하소연 작성 시 *"공개 채널입니다. 상대에게 DM으로 보내시겠습니까?"* 팝업 노출.
* **[권장 8] 스레드 직전 대화 맥락 5개 참고 (F-12)**: 같은 대화방의 직전 메시지 최대 5개(2,000자 이내)를 AI에게 전달하여 앞뒤 문맥에 맞는 교정 도출. ("직전 대화 N개 참고함" 노출 & 끄기 가능).
* **[권장 9] 초기 3초 퀵 온보딩 (F-15)**: 최초 사이드 패널 오픈 시 내 언어, 주 협업 국가, 기본 톤 3문항 설정으로 콜드 스타트 즉시 해결.
* **[권장 10] 승인 문장 '스니펫' 저장소 (F-16)**: 마음에 드는 교정문에 `[스니펫 저장]` 버튼을 눌러 사이드 패널에 보관 후 원클릭 재사용.
* **[권장 11] 개인 학습 내역 열람 및 개별 삭제 (F-17)**: AI가 학습한 내 수정 패턴(Diff)을 사람이 읽을 수 있는 문장으로 사이드 패널 프로필 탭에 투명하게 보여주고 개별/전체 삭제 지원.
* **[권장 12] 상시 노출 회의 시간 추천 & 게이미피케이션 (Token Economy)**: `[🕒 회의 시간 추천]` 버튼, 구글/아웃룩 칼렌더 실제 빈 시간 감지, 시차 충돌 시 양보/미니게임 제안. **양보 시 서비스 내 재화(포인트/토큰) 보상 지급!**
* **[권장 13] 문화적 오해 3초 진단 체크리스트 & 통화/단위 실수 방지 자동 병기 & 상대국 연휴 알림**.

## 🛠 6. 상세 기술 스택 및 시스템 아키텍처

### 1) 프론트엔드 (Chrome Extension & Web Dashboard)
* **Core Framework**: `React 18` + `JavaScript (ES6+)`
* **Extension Build Engine**: `Vite 5` + `@crxjs/vite-plugin` (HMR 및 크롬 익스텐션 자동 번들링)
* **Styling**: `Vanilla CSS` (디자인 시스템 토큰: `--primary-orange: #ff6b00`, `--primary-green: #10b981`)
* **Chrome Extension Core APIs**: `chrome.sidePanel`, `chrome.runtime`, `chrome.storage.local`, `Selection API`

### 2) 백엔드 & 데이터베이스 (Backend & DB)
* **Serverless Runtime**: `Node.js 22` + `Firebase Cloud Functions`
* **Authentication**: `Firebase Auth` (구글 소셜 로그인 및 B2B 팀 역할 권한 제어)
* **Database**: `Firebase Firestore` (NoSQL - 개인 선호도, B2B 용어집, 팀 협업 지수, 재화 토큰 내역 저장)
* **Data Scraper (Cron Job)**: `Node.js` + `Cheerio` (주기적으로 각국 최신 밈 및 공휴일 데이터 정기 크롤링)

### 3) AI 파이프라인 (LLM & Prompt Architecture - 단일 통합 호출 G6)
* **Main LLM**: `OpenAI API` (표준 API 사용 확정 — Azure OpenAI는 v2 로드맵 반영)
  * 🔴 **로컬 개발·테스트에 한해 Gemini API를 대체 provider로 쓴다** (2026-08-12 사용자 결정). **배포·제출 경로와 최종 판정 기준은 OpenAI로 불변** — 두 경로는 같은 payload·같은 반환 JSON 계약을 쓰며 `src/core/refine/providers/`에서 갈린다.
* **단일 통합 호출 API (`POST /v1/refine`)**:
  * 3~5초 이내 속도를 위해 **순차 호출을 전면 금지**하고 1회 단일호출로 구조화된 JSON 데이터 반환.
  * **반환 객체:** `refined` (교정문), `backTranslation` (역번역), `detectedIntent` (하소연 여부), `ticket` (3단 티켓), `appliedGlossary` (용어 적용내역), `urgency` (긴급도 판정결과).
