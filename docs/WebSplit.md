## 단계

### A — 지금 (제출 8/21 전)
- 사이드패널: **홈 + 설정** 중심. 용어집·저장 문구·예약은 탭 대신 접힌 섹션으로 줄인다.
- 웹: 이미 배포된 `dashboard/`를 **소개 + B2B 데모 + 도움말**로 두고 확장에서 링크.
- 🔴 **데이터는 한 건도 서버로 보내지 않는다.**

### B — 나중
- S31(로그인)이 **선행 조건이다.** 계정이 없으면 동기화할 대상이 없다.
- 이전 대상 표의 항목을 동의받아 Firestore로. 금지 표는 로컬에 남는다.
- 확장은 "쓰는 자리", 웹은 "관리하는 자리"로 역할을 나눈다.

## B를 싸게 만들기 위해 지금 지킬 것

1. **데이터 접근은 `src/lib/*.js`를 통해서만 한다.** 컴포넌트가 `chrome.storage`를 직접 부르지
   않는다 — 지금도 그렇게 되어 있고, 이걸 깨면 B에서 호출부를 전부 찾아 고쳐야 한다.
2. **판정·계산은 `src/core/`에 순수 함수로 둔다.** 웹에서도 그대로 재사용된다
   (`scripts/sync-core.mjs`가 이미 functions로 복사하는 것과 같은 구조).
3. **새 저장 키를 만들 때 위 두 표 중 어디에 속하는지 `src/lib/storage.js` 주석에 적는다.**
