## 2. 상세 설명 (스토어 「설명」 칸)

```
해외 동료에게 보내는 업무 메시지를, 보내기 전에 한 번 더 다듬어 주는 도구입니다.

■ 다듬기 — 입력창에서 글을 선택하면 SAI 버튼이 뜹니다. 상대 언어·긴급도(Critical/Normal/Low)에 맞게 고치고,
  무엇을 왜 바꿨는지와 상대에게 어떻게 읽히는지(역번역)를 함께 보여 줍니다.
■ 뜻 풀기 — 받은 메시지를 선택하면 직역, 실제 의도, 겉보기와 실제 긴급도, 요구되는 행동을 정리합니다.
■ 회신 초안 — 받은 메시지에 대한 답장 초안을 만듭니다.
■ 상대의 시간대 — 상대가 퇴근 시간이면 현지 근무 시간에 보내도록 알려 줍니다.
■ 용어집·저장 문구 — 자주 쓰는 용어를 일관되게 지키고, 자주 보내는 문구를 꺼내 씁니다.
■ 팀(선택) — 팀 용어집을 공유하고, 팀 단위 협업 지표(숫자 합계)를 대시보드로 봅니다.

단축키: Alt+D 선택한 문장 다듬기·뜻 풀기 / Alt+S 사이드 패널

개인정보
- 메시지 본문은 SAI 서버나 데이터베이스에 저장하지 않습니다. 결과를 만들기 위해 AI 서비스(Anthropic Claude,
  장애 때만 Groq)로 전송될 뿐이며, 두 회사 모두 API 입력을 AI 학습에 쓰지 않습니다.
- 키·카드번호·주민등록번호 같은 민감정보는 전송 전에 기기에서 막습니다.
- 서버에 남는 것은 계정 정보, 직접 입력한 설정·용어집, 횟수 같은 숫자뿐입니다.
```

근거: 기능 — Spec §1·`src/manifest.js:114-119`(단축키). 개인정보 — `dashboard/public/privacy.html` 1·2·5절.
