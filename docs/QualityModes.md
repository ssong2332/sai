## 금지 (다른 모든 것보다 우선)
- 🔴 확장은 모델을 보내지 않는다 — 모드 **이름**(`quality`)만. 모델·사고·effort는 서버 표에서만(요청 조작·폴오버 꺼짐 방지).
- 🔴 표 밖 값·없음은 기본 모드. 옛 확장도 기본 모드로 다듬는다.
- 🔴 로그·응답에 모델명을 싣지 않는다(응답에는 모드 이름 `quality`만). 본문 미저장(Spec 필수 5)은 그대로.
- 🔴 기준을 결과에 맞춰 바꾸지 않는다 — 아래 표는 측정 **전에** 정했다.
