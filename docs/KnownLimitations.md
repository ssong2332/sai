# 알려진 한계 (Known Limitations)

2026-11-07 전수 점검에서 찾았지만 **설계상 지금은 고치지 않기로 한 항목**의 기록이다(사용자 결정 「알려진 한계로 기록」).
결함이 아니라 의도된 동작이거나, 고치는 비용이 지금 위험보다 큰 항목이다.

## 금지
- 이 표의 항목을 **「고쳤다」로 보고하지 않는다.** 고치면 이 표에서 행을 지우고, 그 PR 번호를 「이력」에 적는다.
- 새 항목은 근거(파일:줄, 실측)가 있을 때만 추가한다. 추정이면 「추정」이라고 쓴다.
- 이 문서는 Spec보다 아래다. Spec과 충돌하면 Spec이 이긴다.

## 판정 기준
| 조건 | 분류 |
|---|---|
| 사용자 데이터·돈이 새거나 남이 볼 수 있다 | 한계로 두지 않는다 → 바로 고친다 |
| 품질·편의 문제이고 우회 수단이 있다 | 한계로 기록 가능 |
| 서버 구조 변경이 필요하고 지금 트래픽에서 위험이 낮다 | 한계로 기록 가능 + 「다시 볼 때」 조건 명시 |
