## 금지 (다른 모든 규칙보다 우선)
- 이 표의 케이스를 **통과시키기 위해 프롬프트를 케이스 문자열에 맞추지 말 것**(과적합). 규칙을 고치고 케이스는 그대로 둔다.
- 실행하지 않은 케이스를 "통과"로 기록하지 말 것. 미실행은 `-`로 남긴다.
- 케이스를 **삭제하지 말 것**. 부적절하다고 판단되면 사유를 적고 `제외` 표시만 한다(삭제하면 회귀 수치가 조용히 좋아진다).

## 판정 방법
각 케이스는 두 축으로 자동 판정한다.
- **필수 포함**: 변환문에 이 값(또는 동등한 의미의 값)이 존재해야 한다. AC-006의 "유지"는 **의미·값 보존**이며 문자열 동일성이 아니다(Planning Decision #53).
- **금지**: 변환문에 이 표현이 나타나면 실패.

```
케이스 통과 = (필수 포함 전부 존재) AND (금지 전부 부재)
AC 통과   = 해당 AC의 케이스가 요구 건수만큼 전부 통과
```

🔴 **(v1.6) 위 "두 축으로 **자동** 판정한다"에는 예외가 두 개 있다. 예외를 모르면 통과 불가능한 AC를 통과했다고 기록하게 된다.**
- **T-U06**(C1 긴급도) — **전량 사람 판정**, 자동 러너에 넣지 않는다(기존, 표 B).
- 🔴 **AC-045 10건(U-01~U-10)** — **자동 절반 + 사람 절반**이다. `필수 포함` 열의 *"확인 요청 문장"·"회신 요청"* 류는 **문자열이 아니라 문장의 기능**이라 러너가 판정할 수 없어 `needs-human-review`로 남는다. **기록 형식·루브릭·합산 규칙은 "실행 기록"의 표 A-1에 확정돼 있다** — 사람 판정 없이는 **AC-045가 `10/10`에 도달하지 않는다.**

### 이모지 판정 데이터 — **국가 라벨 없음**

> ⚠️ **원안 채택하지 않음(PRD Planning Decision #71)**: 사용자가 제공한 10종은 "일본에서 🙏는 사과·간청" 같은 **국가 단위 일반화**였다. 그대로 코드에 넣으면 근거 없는 일반화를 제품에 내장하게 되어 Planning Decision #6(국가 스테레오타입 금지)에 걸린다. **데이터 형태를 아래로 바꿔서만 수록한다.**

**(v1.2 확정 — 사용자 결정 ②, PRD Planning Decision #77) 데이터는 위험도 3단계뿐이다.**

| 위험도 | 이모지 | 의미 |
|---|---|---|
| **높음** | 🙏 ❤️ 💦 | 해석이 크게 갈릴 수 있음 |
| **중간** | 👍 😂 🔥 😅 | 갈릴 수 있음 |
| **낮음** | 😊 ✅ 🆗 | 대체로 안정적 |

| 필드 | 값 |
|---|---|
| `emoji` | 대상 이모지 |
| `risk` | `높음` / `중간` / `낮음` — **고정 룩업**(결과 안정성 확보) |
| ~~`country` / `meaning_by_country`~~ | **필드 자체를 만들지 않는다**(AC-056 ①: 스키마 grep으로 확인) |

**경고 발동 규칙(AC-056 ②)**: `risk ∈ {높음, 중간}` **AND** (해당 상대의 #24 규약 또는 자기신고 프로필의 이모지 항목이 `미사용/거의 안 씀` **또는** 값 없음) → 경고 + 대안. 규약에 "이모지 사용 OK"가 있으면 **경고하지 않는다.**

**경고 문구(확정)**: **"이 이모지는 해석이 갈릴 수 있습니다 — 상대와 합의된 규칙이 없습니다"**

> **왜 이 형태가 Decision #6·#50과 정합하는가**: "해석이 갈릴 수 있다"는 **검증 가능한 사실 진술**이고 국민성 서술이 아니다. 국가·지역을 언급하지 않으며, 어느 해석이 옳은지 단정하지도 않는다. 반면 원안("일본에서 🙏는 사과")은 국가 단위 일반화라 #6 위반이다.
> ⚠️ **위험도 3단계 배정 자체는 측정치가 아니라 판단(추정)** 이다. 발표에서 "조사 결과"로 말하지 않는다.
